# Git Notice 📝

Учебный репозиторий для практики работы с системой контроля версий Git и сервисом GitHub.

## Описание проекта
В этом проекте собраны шпаргалки по базовым командам Git и правилам оформления коммитов по стандарту Conventional Commits.

## Структура репозитория
* `commands.txt` — список основных команд Git с кратким описанием.
* `commits-rules.txt` — правила написания сообщений коммитов (Conventional Commits).
* `task.md` — текст домашнего задания и чек-лист выполнения.

## Используемые технологии
* Git
* GitHub
* Markdown
